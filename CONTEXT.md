# AI Support Desk

An AI-assisted support workflow for a fictional SaaS product. Project work is tracked in GitHub Issues; a support ticket is a request handled by the application.

## Language

**Support ticket**:
A customer's request for help, tracked from submission through resolution.
_Avoid_: Ticket (when it could mean a GitHub issue)

**Answer draft**:
An AI-suggested response to a support ticket, with references to relevant product documentation. It has not been approved for delivery.

**Approved reply**:
An answer draft reviewed and accepted by a person for delivery to the customer.
